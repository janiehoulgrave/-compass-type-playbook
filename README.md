# Compass Type Playbook

Interactive font style guide for Compass agents. Agents enter their name, learn why type consistency matters, answer four questions, get matched to one of 12 type styles, and download a two-page PDF style guide.

Static site: no build step, no framework.

- `index.html`: the whole app
- `fonts/`: Compass Display, Serif, Serif Text and Sans (web versions)
- `vercel.json`: font caching and keeps the site out of search engines

Compass fonts are licensed for use by Compass and its subsidiaries only. Keep this repository private.
